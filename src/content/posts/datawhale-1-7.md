## 存储层级

| **层级（比喻）**             | **谁能用** | **容量参考**                   | **模拟耗时** | **核心特点**                                                                                                   |
| ---------------------------------- | ---------------- | ------------------------------------ | ------------------ | -------------------------------------------------------------------------------------------------------------------- |
| **寄存器**（工具台）         | 单个线程私有     | 每个线程最多 256 个（1 个装 1 个数） | 1 周期             | 速度最快。局部变量（如 `float s = 0;`）默认放这里；用超了会溢出到显存变慢，且用得越多，同时待命的线程越少。        |
| **共享内存 LDS**（车间货架） | 同一线程块共享   | 每个工作组处理器（WGP）128 KB        | 10 周期            | 需手动申请：HIP 写 `__shared__ float box[32];`，Python 写 `box = shared(32)`。别的线程块看不到，且不会自动清零。 |
| **缓存**                     | 硬件自动管理     | L2 缓存 8 MiB，Infinity Cache 64 MB  | 30 周期            | 代码无法直接指定。从显存取数必经此处，取过的数会留一份，下次再取若命中就不用去显存。                                 |
| **显存**（城外仓库）         | 所有线程共享     | 16 GB GDDR6                          | 100 周期           | 容量最大、速度最慢，是寄存器的 100 倍耗时。                                                                          |
| **CPU 内存**                 | 仅 CPU 可用      | 视主机而定                           | 最远               | GPU 线程够不着，必须通过 PCIe 5.0 x16 总线与显存互相拷贝。                                                           |

## 数据流动路径

* **进来：** CPU 内存 $\rightarrow$ 拷进显存 $\rightarrow$ 经过缓存 $\rightarrow$ 取进寄存器计算。
* **出去：** 寄存器算完 $\rightarrow$ 存回显存 $\rightarrow$ 拷回 CPU 内存。
* **例外：** 共享内存（LDS）不在这条路上，它由同一线程块内的线程**手动**写入和读取。

## 选址原则

核心原则：在够得着、放得下的前提下选最近的一层

* **单个线程自己用的中间变量** $\rightarrow$ 放**寄存器**。
* **同一线程块内部交接的数据** $\rightarrow$ 放**共享内存（LDS）**。
* **所有线程块都要读、或算完要传回 CPU 的数据** $\rightarrow$ 放**显存**。

## 区分代码中使用的存储层级

| **存储位置** | **代码特征**                                                                 | **常见写法**                   |
| ------------------ | ---------------------------------------------------------------------------------- | ------------------------------------ |
| **寄存器**   | 核函数内部直接定义的**普通局部变量**（无特殊关键字）                         | `float s = 0;`、`int t = ...;`   |
| **共享内存** | 核函数内部带有 **`__shared__`关键字** 的变量（Python 风格为 `shared()`） | `__shared__ float box[32];`        |
| **显存**     | 通过**核函数参数传进来的指针**（在 CPU 端提前分配地址并拷入数据）            | 参数 `float* a`，以及读写 `a[i]` |

## 案例解析：4 排数对齐相加

任务：32 个线程，每个线程 `t` 把 4 排数中每排第 `t` 个数相加，存入 `out[t]`（`a` 和 `out` 都在显存）。

```cpp
__global__ void add_rows(float* a, float* out, int n, int m) {
    int t = blockIdx.x * blockDim.x + threadIdx.x;
    float s = 0;                 // 寄存器：放中间累加和
    for (int k = 0; k < m; k++) {
        s += a[k * n + t];       // 只从显存读输入
    }
    out[t] = s;                  // 算完一次性写回显存
}
```

### 有多个不同的线程，为什么不使用LDS？

因为不同的线程并没有共享数据的需求，每个线程各算各的。
