## 核心概念

* **缓存行：** 显存缓存分配和管理空间的最小单位。
* **合并访存：** 同一线程束（32 个线程）同时执行访存指令时，硬件将落入同一缓存行的请求合并为一次访存事务。地址连续时，32 个 `float` 合并为 1 次访问；地址分散时，拆分为多次访问，有效带宽下降。
* **访问步长：**同一轮循环里，相邻两个线程（例如线程 0 和线程 1）读取的数组下标差值。比如缓存行大小是32，步长为1最多一次读32个，步长为4最多一次读8个。

## 多任务访存事务分配

| **分配方式**       | **下标公式** | **单线程任务分布**                                 | **同轮相邻线程访问模式**                                                      | **128 元素向量加法总事务数** |
| ------------------------ | ------------------ | -------------------------------------------------------- | ----------------------------------------------------------------------------------- | ---------------------------------- |
| **每线程连续分配** | `i = t * m + k`  | 线程 0 算 `0~3`，线程 1 算 `4~7`                     | 第 0 轮访问 `0, 4, 8 ... 124`，访问步长为 4，每次读取跨 4 个缓存行                | **48 次**                    |
| **每线程跨步分配** | `i = k * T + t`  | 线程 0 算 `0, 32, 64, 96`，线程 1 算 `1, 33, 65, 97` | 第 0 轮访问 `0~31`（第 0 块），第 1 轮访问 `32~63`（第 1 块），访问步长始终为 1 | **12 次**（理论最小值）      |

## 例子：分段求和

派 32 个线程，每人各加 4 个数，输出 32 个部分和存入 `part[0] ~ part[31]`

```cpp
__global__ void part_sum(float* a, float* part, int m) {
    int t = blockIdx.x * blockDim.x + threadIdx.x;
    int T = gridDim.x * blockDim.x; // 总线程数
    float s = 0;
    for (int k = 0; k < m; k++) {
        int i = k * T + t;          // 保证同轮相邻线程读取相邻地址，步长为1，尽可能合并访问
        s = s + a[i];
    }
    part[t] = s;
}
```
